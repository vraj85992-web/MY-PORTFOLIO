## 🛠️ Technologies Used

- **HTML5**: Semantic tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<figure>`, `<footer>`, `<form>`).
- **CSS3**: 
  - CSS Custom Properties (`:root` design system tokens)
  - Flexbox (1D layouts, navigation, button clusters, form fields)
  - CSS Grid (2D layouts, hero split, skills bento, project showcase, contact grid)
  - CSS Transitions (`cubic-bezier` timing functions for hover states)
  - CSS Keyframe Animations (`@keyframes floatAvatar`, `@keyframes pulseGlow`, `@keyframes ping`)
  - Media Queries (Mobile-first responsive breakpoints: `480px`, `768px`, `1024px`)
  - Pure CSS interactive mobile navigation menu (checkbox hack — zero JavaScript required)

## 🧠 Concepts & TA Evaluation Guide

| Category | Implementation in this Portfolio |
|---|---|
| **Semantic HTML** | Used proper landmarks (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`). Accessible forms with associated `<label>` and `<input>` elements. |
| **Where Flexbox is used** | Sticky navbar (`justify-content: space-between`), button clusters (`gap: 16px`), hero stats pill, timeline badges, and footer alignment. |
| **Where CSS Grid is used** | Hero 2-column split, About bento layout, Skills 3-column cards (`repeat(3, 1fr)`), Projects showcase gallery, and Contact section split. |
| **The Box Model** | Universal `box-sizing: border-box`, controlled padding scales, margin distribution, and border-radii tokens. |
| **CSS Transitions** | All interactive links, buttons, cards, and input fields use `transition: all 0.28s cubic-bezier(0.16, 1, 0.3, 1)` for smooth feedback. |
| **CSS Animations** | `@keyframes floatAvatar` (gentle floating effect), `@keyframes pulseGlow` (breathing aura behind avatar), and `@keyframes ping` (live status pill). |
| **Responsive Design** | Fluid media queries at `1024px` (tablets), `768px` (pure CSS mobile hamburger menu), and `480px` (smartphones). Tested with DevTools. |
