About Me

Story

Creating With Precision & Purpose

I am a dedicated frontend developer committed to mastering the fundamentals of the web. My journey began with a curiosity for how design transforms into functional interactive software, which quickly grew into a passion for writing semantic, accessible markup and scalable CSS layouts.

Rather than relying prematurely on heavy frameworks, I believe in mastering the core fundamentals first: the CSS Box Model, Flexbox alignment, Grid systems, and media query breakpoints. When the foundation is strong, everything built on top is resilient.
